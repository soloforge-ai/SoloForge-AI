# SoloForge Affiliate Agent

Status: MVP V0 planning and implementation.

## Goal

Build an internal-first responsive web workflow that helps discover affiliate programs, evaluate opportunities, generate AI-assisted content packages, track outbound clicks, and learn from real performance.

Core loop:

Discover → Analyze → Save → Create Content → Publish → Track → Learn

## Product principles

- Revenue validation before feature expansion.
- AI may generate most content, but factual/product claims that imply first-hand use must be human verified.
- Affiliate terms such as commission, cookie window, pricing, and restrictions are not trusted solely from model output.
- Every published content item records the tools actually used.
- Every video should be able to generate a standard end card listing the tools used.
- V0 is an internal tool for Ai HackWork first; SaaS comes only after evidence of demand and retention.

## MVP modules

1. Discover
2. Program Detail / Analyze
3. My Programs
4. Content Factory
5. Tracking
6. Performance
